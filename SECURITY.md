# Security

Found a way to make Genrix act without the user's OK, read something it shouldn't, or leak
data? Please report it privately to **contact@h4harshill.com** (not a public issue), with the
steps to reproduce and the app version. You'll get an answer as soon as possible.

Things that are in scope include: getting around the Allow card, the "Your turn" handover,
the blocked-apps list, the untrusted-text guard (text on screen, in messages, emails or
invites making Genrix call, send, book or change its memory), voice-reply consent, or the
refusal to store passwords, PINs, OTPs and card numbers.

Only download Genrix from this repository's Releases page; the install guide lists the
signing key's fingerprint.
