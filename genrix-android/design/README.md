# Genrix design

The app's design system lives in `app/src/main/java/app/genrix/android/ui/Theme.kt` (colours, type scale, shapes), `Components.kt` (shared parts) and `Orb.kt` (the animated AI core).

Palette (dark first): background #070A12, elevated #0B1120, card #101827, elevated card #151F31, cyan #64D9FF (active), violet #8B7CFF (secondary AI detail), glow #3B82F6, text #F2F6FF / #9BAAC2 / #66758D, success #55E6A5, warning #FFC66D, error #FF6B7A.

`genrix-neural-preview.html` is an interactive preview of the current navy and cyan design (open it in a browser). `genrix-preview.html` and the Figma file are an earlier concept in black and lime; they are kept for reference and do not match the current palette.
