# Installing Genrix

Genrix isn't on the Play Store, so it's installed from the APK file.

1. **Download** `Genrix-<version>-Android.apk` from the [Releases](../../releases) page,
   on your phone.
2. **Open the APK.** Android asks to allow installing from your browser or Files app
   ("Install unknown apps"): allow it for that app, then tap **Install**.
3. **Open Genrix** and follow the setup: paste your free Gemini API key from
   [Google AI Studio](https://aistudio.google.com/apikey) and allow the microphone.

## Optional features

- **Phone control** (use apps for you): Genrix → Settings → Phone control. On Android 13+,
  Android first blocks this for installed-from-file apps: open **Settings → Apps → Genrix →
  ⋮ (top right) → Allow restricted settings**, then turn on Genrix under
  **Settings → Accessibility → Installed apps**.
- **What did I miss? / watch my messages:** Genrix → Settings → Notifications → Turn on.
- **Floating orb:** Genrix → Settings → Floating orb → allow "Display over other apps".
- **Keep it running** on Samsung, Xiaomi, Oppo, Vivo: allow Genrix under Battery → Unrestricted.

## Updating

Download the newer APK and open it. It installs over the old one only if it was signed with the same key as the old one.

## Uninstalling

Settings → Apps → Genrix → Uninstall. This deletes everything Genrix stored.
